# プロジェクト概要
プロジェクト名: Idisclosure (#1, #2, #3)
チームメンバー詳細(#1): Kyarasu, minttto, RiST-Maomao, sabanomisoni11, toaru05
チームメンバー詳細(#2): Kyarasu, RiST-Maomao, sabanomisoni11, toaru05
チームメンバー詳細(#3): Kyarasu
概要: 最初に設定した自身のSecretIDを漏洩させないようにセキュリティを意識しながら、相手のSecretIDを盗むために様々なサイバー攻撃ツールを駆使して攻撃を仕掛ける心理戦ハッキングゲーム。

# 制作背景
プログラミングを学び始める中で、以下のような課題を感じた。
1. パソコン初心者にとって、セキュリティ分野は学習ハードルが高いこと 
2. セキュリティを学ぶ際にはサイバー攻撃の理解が必要となるが、実際に試すには法律的・倫理的な制約があり、実践的に学ぶ機会が限られていること 
これらの課題を解決するため、ゲーム形式でサイバーセキュリティを学べるプロダクトを開発するに至った。

# ペルソナ
- 情報系初学者
- セキュリティに興味はあるが学習ハードルを感じている人
- "ハッキング"のかっこよさを体験したい人

# ルール
## 基本ルール
-  ユーザー名・誕生日・Secret IDを設定してゲーム開始 
-  Secret IDは推測されやすいほど初期資金が多くなる(リスクとリターン設計) 
-  他プレイヤーとマッチングして対戦 
## 勝利条件
-  制限時間終了時に最も多くのゲーム内通貨を保持 
-  他プレイヤーがSecret ID漏洩によりリタイア 
- 他プレイヤーがバッテリー切れによるリタイア
## 主なシステム
1. PC画面
-  所持金、バッテリー、IPアドレスの確認 
-  各機能（Firewall / Terminal / Browser）への遷移 
2. Firewall
-  特定IPを登録することでそのIPからの攻撃を防御 
3. Terminal
-  他プレイヤーへの攻撃 
-  WiFi内に保存されているプレイヤー全員の通信履歴の閲覧(IPのペアで表示)
-  アンチウイルスソフトウェアの起動 
-  他プレイヤーのSecret IDの解析 
4. Browser
-  SNSから他プレイヤーの情報を取得(誕生年、誕生日など) 
-  アイテムのダウンロード(早押し・発生には確率要素あり)
-  フィッシングのリスクあり 
5. Server
- PCと同様の機能
-  フィッシングサイトの構築 
-  ウイルス侵入や資金奪取が可能

# ルールにおいて工夫した点
1. 勝利条件の分散化
勝利条件を複数設定することによって戦略がより多くなるように設計しました。
2. 心理戦要素の導入
常に本当なのか嘘なのかわからない状態を作り出すことによって緊張感を演出しています。
3. カスタマイズ性の確保
平等に与えられた条件下で勝利するためにどこにどれだけの時間や資源を費やすかを自由度高く自分で決めることができます。
4. 終了の可視化
ゲームが永遠に続くことがなく、ちょっとずつゲームが終わりやすくなっていくことによって、プレイヤーに絶望を与えないようにすることを意識しました。
5. 時間の配慮
1ゲームが長くなりすぎないように設計することによって複数回ゲームがしやすいようにし、同じ時間で満足感がより多く得られるように設計しました。
6. 報酬とリスク
戦況が良くなるためにはその分状況が悪くなるリスクを背負う必要があり、万能な一手を存在させないように心がけました。
